MINHAS FINANÇAS — PWA
Desenvolvido por Gabriel Ramos

Instalação no iPhone:
1. Publique esta pasta em hospedagem HTTPS.
2. Abra o endereço no Safari.
3. Compartilhar > Adicionar à Tela de Início.
4. Abra pelo novo ícone.

A splash dura 2,2 segundos. Dados ficam no armazenamento local do navegador.
Face ID real não pode ser chamado por um PWA da mesma forma que no app nativo SwiftUI.
